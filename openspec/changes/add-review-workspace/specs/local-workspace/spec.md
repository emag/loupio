# Spec Delta

## Purpose

Lupio の local-workspace に関する外部から観測できる振る舞いを定義し、合意した MVP の利用手順と完了条件を検証できる契約にする。

## ADDED Requirements

### Requirement: 端末内の作業保存
アプリは記録・設定・優先指定・対応状況を端末内に保存し、オフラインでも保存済み一覧の閲覧とローカル記録の編集を提供しなければならない（MUST）。

#### Scenario: 通信断中の編集
- **WHEN** オフラインでメモと対応状況を変更して再起動する
- **THEN** 変更内容を保存済みデータから復元する

### Requirement: 更新と失敗表示
アプリは起動時・起動中の約一分ごと・手動で更新し、最終成功時刻と失敗を表示しなければならない（MUST）。

#### Scenario: 取得失敗
- **WHEN** 更新がネットワークエラーで失敗する
- **THEN** 一覧と記録を保持し最終成功時刻を進めず失敗を表示する

### Requirement: バックアップと復元
アプリはメモ・確認記録・設定を手動で書き出し復元でき、認証情報を含めてはならない（MUST NOT）。

#### Scenario: 異常なファイル
- **WHEN** 不正または未対応形式のファイルを復元しようとする
- **THEN** 既存の記録を変更せず失敗を表示する

### Requirement: 対応 OS と起動性能
アプリは macOS と Linux で動作し、約三十件の保存済み一覧を起動から三秒以内に操作できなければならない（MUST）。

#### Scenario: 保存済み一覧の起動
- **WHEN** 測定対象端末で三十件を保存したアプリを起動する
- **THEN** ネットワーク完了を待たず三秒以内に一覧操作が可能になる

### Requirement: 連続利用と応答性
アプリは通信中も一覧切り替え・メモ入力を可能にし、約八時間の定期取得中にフリーズや操作感の悪化を起こしてはならない（MUST NOT）。

#### Scenario: 長時間利用
- **WHEN** 三十件を管理し約八時間の定期取得と一日十件相当の確認操作を行う
- **THEN** 一覧操作とメモ入力を継続でき、検証計画で定めた性能基準を満たす
