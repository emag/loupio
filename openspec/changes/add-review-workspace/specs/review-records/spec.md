# Spec Delta

## Purpose

Lupio の review-records に関する外部から観測できる振る舞いを定義し、合意した MVP の利用手順と完了条件を検証できる契約にする。

## ADDED Requirements

### Requirement: 四つの確認観点
アプリは仕様との一致・既存動作との整合・テストの十分性・セキュリティについて未確認・確認済み・対象外と短いメモを保存できなければならない（MUST）。

#### Scenario: 観点の保存
- **WHEN** 利用者が観点の状態とメモを変更して再起動する
- **THEN** 変更した内容を復元する

### Requirement: 変更後の再確認
アプリは追加コミット時に以前の観点記録を保持して再確認が必要と表示し、返信のみなら観点記録を維持しなければならない（MUST）。

#### Scenario: 追加コミット
- **WHEN** 四観点を確認済みにした後に追加コミットを検知する
- **THEN** 以前の結果とメモを残し四観点に再確認の必要性を示す

### Requirement: 返信時の記録保持
アプリはコメントのみの更新で確認観点を未確認に戻してはならない（MUST NOT）。

#### Scenario: 返信のみ
- **WHEN** 作者が返信しコードの変更はない
- **THEN** PR を要対応にし観点の確認結果は維持する

### Requirement: 外部の根拠とレビュー結果
アプリは仕様書・Jira・Slack・AI 結果などへのリンクと抜粋メモを PR に保存し、リンクを外部で開けなければならない（MUST）。

#### Scenario: 根拠の保存
- **WHEN** PR に仕様リンクと AI の指摘の抜粋を追加する
- **THEN** 次回起動時にも参照できる

### Requirement: 外部でのコードレビュー
アプリは対象 PR を外部の GitHub で開く操作を提供しなければならない（MUST）。

#### Scenario: レビューへ移動
- **WHEN** 利用者が PR を開く
- **THEN** 該当 GitHub PR を外部ブラウザで開く
