# Spec Delta

## Purpose

Lupio の github-connection に関する外部から観測できる振る舞いを定義し、合意した MVP の利用手順と完了条件を検証できる契約にする。

## ADDED Requirements

### Requirement: 単一アカウントの接続
アプリは GitHub.com の一つのアカウントへのブラウザ経由の認証を提供し、認証情報を OS の資格情報保管機能に保存しなければならない（MUST）。

#### Scenario: 接続と資格情報保護
- **WHEN** 利用者が接続を完了した
- **THEN** アカウントが識別され、認証情報がメモや設定の平文ファイルに保存されない

### Requirement: 対象チームの選択
アプリは所属チームから依頼の収集対象を選択できなければならない（MUST）。

#### Scenario: チームの絞り込み
- **WHEN** 所属チームの一部を選択した
- **THEN** 選択チーム宛ての依頼と個人宛ての依頼が収集対象になる

### Requirement: 接続制約の通知
アプリは認証や組織へのアクセスが拒否された場合に、接続状態と失敗を表示しなければならない（MUST）。

#### Scenario: 組織の拒否
- **WHEN** 組織の制約で PR を取得できない
- **THEN** 取得できたと偽らず、保存済みの作業記録を保持する
