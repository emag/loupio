# Proposal

## Why

現在利用している GitHub クライアントでは、対応すべき PR の探索と長時間利用時の安定性に課題がある。個人のレビュー待ち一覧と確認観点を管理し、作業を再開しやすくする。

## What Changes

- macOS・Linux 用の個人向けデスクトップアプリを新規作成する。
- 個人・選択したチームへの依頼を収集し、対応状況と再確認理由を表示する。
- 四つの確認観点、メモ、根拠リンク、AI レビューへのリンクを保存する。
- ローカル保存、オフライン編集、定期同期、バックアップに対応する。
- コード閲覧・コメント・承認は外部の GitHub／IDE で行う。

## Capabilities

### New Capabilities

- github-connection: 単一アカウントの接続、チーム選択、認証情報の保管。
- review-queue: 依頼の収集、対応状況、優先順、除外とドラフトの扱い。
- review-records: 確認観点と履歴、メモ、根拠・AI 結果の参照。
- local-workspace: ローカル保存、更新、バックアップ、性能と対応 OS。

### Modified Capabilities

なし（新規アプリケーション）。

## Impact

GitHub API と OS の資格情報ストアを利用する。組織の承認制約、認証方式、Linux のランタイム依存は技術調査で確認する。実装済みの振る舞いはまだなく、本変更は未実装の提案として保持する。
